# История изменений

## 3.2.2 — 2026-11-24

- Добавлен встроенный выбор исходных каталогов с навигацией по файловой системе Linux; начальная папка — `/home`.
- Если файлы меняются во время создания архива, временный архив отбрасывается, предыдущие архивы сохраняются, а завершённая синхронизация отмечается предупреждением.
- Номер выпуска пакетов установлен в `4`: Debian `3.2.2-4`, RPM `3.2.2-4`.
- В журнал синхронизации добавлен список файлов, изменявшихся во время создания архива.
- Уточнено, что ZIP вместо TAR.GZ не устраняет изменение файлов во время чтения.
- Обновлён значок приложения; он включается в DEB и RPM пакеты из `assets/backup-manager.svg`.

## 3.2.1 — 2026-11-24

- Изменены формулировки интерфейса: приложение описывает синхронизацию локальных каталогов с SMB-сервером.
- Добавлено отображение прогресса выполняющихся заданий.
- Добавлены запуск, остановка, редактирование и удаление заданий.
- Добавлена проверка изменений через `rsync --dry-run` с выводом списка планируемых удалений.
- Добавлен параметр отложенного удаления `--delete-delay`.
- Добавлено создание датированных архивов после синхронизации с настройкой количества хранимых архивов.
- Добавлен раздел восстановления: просмотр хранилища машины, скачивание файлов и восстановление в пустой локальный каталог.
